# flaminyu.github.io

Personal academic homepage of Guofan YU (余国帆).

Style inspired by common HKBU academic GitHub Pages (sidebar + white background).

## Local preview

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080/

## Deploy

Create a public repository named `flaminyu.github.io`, push `main`, and enable GitHub Pages from the root.
